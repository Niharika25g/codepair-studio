# 🚀 CodePair Studio

A professional-grade, real-time collaborative coding platform and cloud execution engine built for technical interviews and peer programming.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, STOMP.js, SockJS-client, Lucide Icons
* **Backend:** Spring Boot, Spring WebSockets (STOMP broker), REST API
* **External Integration:** JDoodle Compiler API for secure cloud-based code execution (Java, Python, JavaScript, C++)

## ✨ Key Features
* **Real-Time Collaboration:** Multi-user live document synchronization via WebSockets.
* **Cloud Execution Sandbox:** Compile and execute code dynamically across multiple programming languages.
* **Room Management:** Generate unique secure workspace rooms with shareable URLs and strict room validation.
* **Modern UI/UX:** Responsive, dark-mode developer interface optimized for high-performance usage.
